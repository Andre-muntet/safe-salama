# Safe Salama

## About

**Safe Salama**

This project was developed as part of an **Invention Sprint** by [Andela](https://www.andela.com/) and the [Open Society Foundations (OSF)](https://www.opensocietyfoundations.org/).

The sprint focused on problem-solving and an invention mindset, with projects developed across three tracks.

I chose the **Safety, Reporting & Protection** track to explore a practical response to challenges around safety information, reporting, and access to protection and support.

## The Problem

The issue is not necessarily a lack of information or reporting systems. The issue is **access** — whether people can reach, understand, and act on the right information when it matters.

## The Solution

And that’s why I thought of **Safe Salama** — a platform designed to make safety information more accessible while connecting people to the help they need.

It builds an informed, verified, and continually learning safety database that powers two sides of the platform:

* **Information & awareness** — helping people discover relevant safety knowledge before and when it matters.
* **Reporting & protection** — facilitating reports and connecting people to appropriate help, with responses informed by the same safety knowledge.

Together, these create a **virtuous cycle**: information helps people stay informed and respond safely; reports contribute new knowledge that can strengthen the information available to others.



## Run the project

Open Git Bash or your preferred terminal and clone the repository:

git clone :https://github.com/Andre-muntet/safe-salama.git

Make sure you are inside the safety-poc directory before continuing.

Install the project dependencies:

```bash
npm install
```

Start the application:

```bash
npm run user-ui
```

Once the application starts, the terminal will provide a local URL, similar to:

```text
http://localhost:3000
```

Open the URL provided in your terminal in a browser to launch **Safe Salama**.

## Conclusion

**Safe Salama** has the potential to reach beyond those who actively report harm — helping people recognize safety concerns, making it easier to reach those who can help, and turning community experiences into knowledge that benefits others.

Features such as **Know Before You Go** can also highlight local patterns and grievances that may deserve attention.

Ultimately, it is about **better-informed people, stronger community knowledge, and better opportunities to act.**
